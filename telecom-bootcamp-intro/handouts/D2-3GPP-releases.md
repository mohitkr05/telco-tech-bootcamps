
# Standard bodies in Telecom

Standards are agreed-upon rules, specifications, or guidelines that are used to ensure the quality, safety, and interoperability of products, services, and processes. They are important because they help to:
 - Promote safety and reliability
 - Improve quality
 - Encourage innovation
 - Facilitate trade

## Telecom Infra Project


The Telecom Infra Project (TIP) is a global community of companies and organizations that are working together to accelerate the pace of innovation in the telecom industry. TIP is focused on developing open, disaggregated, and standards-based infrastructure solutions that deliver the high-quality connectivity that the world needs – now and in the decades to come.

| Release | Year | Key Features |
|---|---|---|
| Disaggregated Cell Site (DCS) | 2017 | A set of specifications for disaggregating the radio unit (RU), distributed unit (DU), and central unit (CU) of a cell site. |
| OpenCellular | 2018 | An open source implementation of the DCS specifications. |
| All-in-One Cloud-Native Open RAN (AIO COR) | 2019 | A set of specifications for deploying a cloud-native Open RAN on a single platform. |
| OpenRAN Radio Software Stack (ORAN-RSS) | 2020 | An open source implementation of the AIO COR specifications. |
| OpenRAN 5G NR | 2021 | A set of specifications for deploying 5G NR using Open RAN technologies. |
| OpenRAN Intelligent Controller (ORAN-RIC) | 2022 | An open source implementation of an Open RAN Intelligent Controller (RIC). |
| OpenRAN E2 Service Model (ORAN-E2SM) | 2023 | An open source implementation of the O-RAN E2 Service Model (E2SM). |

## ONAP

The Open Network Automation Platform (ONAP) is an open source software platform for automating the deployment and management of telecommunications networks. It is a collaborative project led by the Linux Foundation Open Networking (LF Networking) project. ONAP is designed to be a vendor-neutral, open source platform that can be used by any telecom operator to automate their networks.

- Software-defined networking (SDN)
